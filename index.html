ABOUT OUR LAB

情報通信の理論から
リアルワールド実装まで

Wireless Networks & Mobile Systems Laboratory（ワイヤレスネットワーク＆モバイルシステム研究室）では、電波伝搬モデル化・通信プロトコル設計・機械学習を横断し、次世代の広域・高密度ワイヤレスインフラの研究を行っています。

当ラボの特徴は、数理理論の証明にとどまらず、SDR（ソフトウェア無線）を用いた実機プロトタイプ構築や、フィールド実証実験を重視している点です。自動運転、遠隔医療、宇宙データ通信の基盤技術を確立します。

ソフトウェア無線（SDR）テストベッド

USRPやFPGAを用いたリアルタイム信号処理・プロトコル実装環境。

深層強化学習による自律周波数制御

電波環境の動的変化に対応するリアルタイムAI最適化エンジンの開発。

spectrum_optimizer.py 
import torch
from wnms_lab import SpectrumManager, MeshNode

# 6G/7G Dynamic Spectrum Allocation Simulation
class AISpectrumScheduler:
    def __init__(self, num_channels=128):
        self.manager = SpectrumManager(channels=num_channels)
        self.agent = torch.load("models/rl_spectrum_v4.pt")

    def optimize_throughput(self, active_nodes):
        state = self.manager.get_channel_state_information()
        action = self.agent.predict(state)
        return self.manager.allocate_power_and_beam(action)

# System initialized. Target latency: < 1.0ms
print("[WNMS-Lab] Spectrum Optimizer Active.")
RESEARCH AREAS

主軸となる研究テーマ

最先端のワイヤレス通信技術からネットワークシステムアーキテクチャまで、多角的な領域で研究を展開しています。

Beyond 6G / 7G 無線通信

テラヘルツ波（THz帯）通信、超大規模MIMO、Reconfigurable Intelligent Surfaces (RIS) を活用した超高速・大容量伝送制御。

Explore Details

AI駆動型 スペクトラム制御

深層強化学習や連合学習（Federated Learning）を用いた動的周波数共有、干渉軽減、およびリアルタイムリソース割り当て。

Explore Details

非地上系ネットワーク (NTN)

低軌道衛星（LEO）、HAPS（高高度プラットフォーム）、ドローンネットワークを統合した超広域3次元無線アクセス基盤。

Explore Details

ISAC (統合センシング＆通信)

電波を用いて通信を行いながら同時に周りの環境・移動体を高精度にミリ波・レーダーセンシングする統合通信設計。

Explore Details

Ultra-Low Latency & IoT Edge

超低遅延（1ms以下）・超高信頼（URLLC）通信と、マルチアクセス・エッジコンピューティング（MEC）連携。

Explore Details

ワイヤレスセキュリティ & PLS

物理層セキュリティ（Physical Layer Security）と耐量子暗号を応用した次世代セキュア無線ネットワーク。

Explore Details
